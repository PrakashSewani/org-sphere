# Navigation

## Information Architecture

OrgSphere uses a hierarchical navigation structure with the Organization Graph as the primary interface.

---

## Primary Navigation

### Sidebar Navigation

```
┌─────────────────────────────┐
│ 🏠 Home (Dashboard)        │
│ 🌐 Organization Graph      │
│ 👥 Employees               │
│ 📅 Leave                   │
│ ⏰ Attendance              │
│ ✅ Approvals               │
│ 💬 Communication           │
│ 📊 Analytics               │
│ 🤖 AI Assistant            │
│ ⚙️ Settings                │
└─────────────────────────────┘
```

### Top Navigation

```
┌─────────────────────────────────────────────────────┐
│ 🔍 Search...                    🔔 3  👤 John Doe ▼│

```

---

## Navigation Levels

### Level 1: Module

Top-level modules accessible from sidebar.

### Level 2: Section

Sections within each module.

### Level 3: Detail

Specific items within sections.

### Level 4: Action

Actions on specific items.

## Quick Access

### Favorites

- Pin frequently accessed pages
- Custom shortcuts
- Recent items

### Keyboard Shortcuts

- `⌘ + K`: Quick search
- `⌘ + /`: Keyboard shortcuts
- `⌘ + N`: New item
- `⌘ + S`: Save
- `Esc`: Close/cancel
