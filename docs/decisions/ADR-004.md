# ADR-004: Backend Technology Stack

## Status

Accepted

## Date

2026-07-12

## Context

OrgSphere needs a robust, enterprise-grade backend framework. The team requires strong typing, dependency injection, and clean architecture patterns for maintainability and scalability.

## Decision

OrgSphere will use .NET 10 with Clean Architecture for the backend.

### Technology Stack

| Component | Choice | Rationale |
|-----------|--------|-----------|
| Framework | .NET 10 | Latest LTS, high performance, strong typing |
| Architecture | Clean Architecture | Clear separation of concerns, testable |
| CQRS | DispatchR.Mediator | Free, high-performance MediatR alternative |
| Validation | FluentValidation | Industry standard, works with CQRS |
| Graph Database | Neo4j | Mature graph DB, excellent .NET driver |
| Container | Docker | Local development, reproducible environments |

### Clean Architecture Layers

```
src/backend/
├── OrgSphere.Domain/          # Entities, interfaces, enums (no dependencies)
├── OrgSphere.Application/     # CQRS handlers, validators, DTOs
├── OrgSphere.Infrastructure/  # Neo4j, repositories, external services
└── OrgSphere.API/             # Controllers, middleware, configuration
```

## Consequences

### Positive

- Strong typing catches errors at compile time
- Dependency injection enables testability
- Clean Architecture enforces unidirectional dependencies
- DispatchR is free and outperforms MediatR
- Neo4j is purpose-built for graph queries
- Docker provides consistent development environments

### Negative

- More boilerplate than Node.js
- Steeper learning curve for graph database
- Need to manage .NET SDK versions
- DispatchR is newer, smaller community than MediatR

### Neutral

- Need to train team on Clean Architecture patterns
- Need to establish repository patterns for graph DB
- Need to design multi-tenant graph schema

## Alternatives Considered

1. **Node.js/TypeScript**: Faster initial development, weaker typing, less enterprise patterns
2. **MediatR**: Commercial license required, DispatchR is free and faster
3. **ArangoDB**: Multi-model, less mature .NET driver
4. **PostgreSQL + AGE**: Graph extension, less native graph performance
