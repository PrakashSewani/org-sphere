# Onboarding

## New Hire Onboarding

Streamlined onboarding process integrated with the Organization Graph.

---

## Onboarding Workflow

### Pre-boarding

```
1. Offer accepted
2. Account created
3. Equipment ordered
4. Welcome email sent
5. Manager notified
6. Team notified
```

### Day 1

```
1. Check-in
2. Orientation
3. Equipment setup
4. System access
5. Team introduction
6. Buddy assignment
```

### First Week

```
1. Company overview
2. Department introduction
3. Role expectations
4. Initial training
5. Check-in with manager
6. Feedback collection
```

### First Month

```
1. Training completion
2. Project assignment
3. 30-day review
4. Goal setting
5. Feedback session
6. Integration assessment
```
