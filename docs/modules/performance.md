## Graph Integration

### Relationships

```
Employee
  ├── HAS_GOAL → Goal
  ├── REVIEWED_BY → Reviewer
  ├── FEEDBACK_FROM → Peer
  ├── ALIGNED_TO → Company Goal
  └── DEVELOPS_SKILL → Skill
```
